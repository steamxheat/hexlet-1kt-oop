# Контрольная точка «ООП»

Темы: объекты и методы, this, классы, приватные поля, наследование, Proxy.

## Что нужно

Node.js, редактор кода, git и аккаунт на GitHub.

## Как сдавать

1. Склонируйте репозиторий:

   git clone <ссылка>

2. Создайте свой репозиторий на GitHub (или сделайте форк) — решения пушите туда.

3. Решите 4 задания в файлах task1-task4. Условие написано в комментарии в начале файла. Код пишите на месте "// ваш код здесь". Код ниже строки "Проверки" не трогайте.

4. Проверяйте себя: запустите файл через node, например

   node task1-playlist.js

   Все строки должны стать зелёными.

5. Запушьте решения в свой репозиторий и пришлите мне ссылку. После пуша GitHub сам запустит проверки: рядом с коммитом появится зелёная галочка (всё решено) или красный крестик (есть ошибки, детали во вкладке Actions).

   Перед пушем можно прогнать все задания сразу: node check.js

## Задания

- task1-playlist.js — объект с методами, this
- task2-wallet.js — класс, приватное поле, геттер
- task3-employees.js — наследование, extends и super
- task4-proxy.js — Proxy, ловушки get и set

Конспекты и документацию использовать можно. Нейросеть может объяснить ошибку, но решение должно быть вашим.
